مساعد راجع بذكاء ✦

مساعد دراسي مجاني يعمل محلياً على جهازك: يشرح الدروس، يلخص ملفات PDF، ينشئ اختبارات، ويتابع الحوار معك.

نموذج محلي مجاني. اختر حجمه ثم حمّله أول مرة؛ سيُخزّن في المتصفح عند توفر المساحة.
اختر درساً ثم استخدم أزرار الشرح أو التلخيص أو الاختبار. أول تحميل يحتاج إلى الإنترنت ويدعم Chrome أو Edge مع WebGPU. لا تحتاج إلى حساب أو مفتاح API للدردشة المحلية.
مرحباً! أنا مساعدك الدراسي في راجع بذكاء. أستطيع شرح الدروس، تبسيط المفاهيم، إعداد ملخصات واختبارات، والإجابة عن أسئلتك. ابدأ باختيار درس أو اكتب سؤالك.
المعالجة تتم على جهازك ولا تُرسل أسئلتك أو نص PDF إلى مزوّد ذكاء اصطناعي خارجي. قد يخطئ النموذج المحلي، وقد تكون إجاباته أضعف من النماذج السحابية؛ راجع المعلومات المهمة مع الدرس أو الأستاذ.
